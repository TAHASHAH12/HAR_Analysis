# Analysis app

WLDM-branded dashboard for the Stake AI citation analysis. React + Vite, no chart library.

```bash
npm install
npm run data      # rebuild public/data.json from the Profound CSV and ../output
npm run dev       # start the app
npm run extract   # parse ~/har-captures/*.har, then rebuild the data
```

Tabs: Overview, Citations, Opportunities, HAR findings (`#overview`, `#citations`, `#opportunities`, `#har-findings`).

## Data

`public/data.json` is generated by `../build_app_data.py` and is not hand-edited. It holds the Profound export plus the sanitised HAR extraction (queries, URLs, outcomes). Raw HAR files are never read by the app.

## Brand

Styled to the WLDM Brand Replication Brief (3 September 2026), internal tool style (section 5.3): beige ground, flat surface panels, ink text, one fluro-yellow accent. Tokens live in `src/index.css`.

`src/fonts/` holds TT Lakes Neue, a paid font licensed to WLDM. Do not redistribute it or publish this app outside WLDM work.
